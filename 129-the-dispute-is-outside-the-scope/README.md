# The Dispute Is Outside the Scope

_A store, a payment protocol and an exchange each set exact rules for an AI agent that spends your money. None of the passages quoted here says who pays when it buys the wrong thing. Set your own limit first._

## How to use

Each `prompt-N.md` file is the prompt itself, with the teaching wrapper
stripped. Open the file, copy the contents, paste into Claude / ChatGPT /
your model of choice. The article (linked above) explains what the prompt
does and what to expect when you run it.
