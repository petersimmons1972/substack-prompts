# Every Budget Was Reasonable

_Our review loop has four limits, and each is sensible on its own line. Multiplied at their ceilings they allow 18,100 model calls, and one of them has no ceiling at all._

Prompts referenced in [Plutarch TX](https://plutarchtx.substack.com) article **146-every-budget-was-reasonable**.

## How to use

Each `prompt-N.md` file is the prompt itself, with the teaching wrapper
stripped. Open the file, copy the contents, paste into Claude / ChatGPT /
your model of choice. The article (linked above) explains what the prompt
does and what to expect when you run it.
