# The Interview Nobody Attended

_We sent an AI subagent to put a batch of questions to me. It reported the task complete. I never saw a question, because it had no way to reach me._

Prompts referenced in [Plutarch TX](https://plutarchtx.substack.com) article **148-the-interview-nobody-attended**.

→ **Read the article:** <https://plutarchtx.substack.com/p/the-interview-nobody-attended>

## How to use

Each `prompt-N.md` file is the prompt itself, with the teaching wrapper
stripped. Open the file, copy the contents, paste into Claude / ChatGPT /
your model of choice. The article (linked above) explains what the prompt
does and what to expect when you run it.
