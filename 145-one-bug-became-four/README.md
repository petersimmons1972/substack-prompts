# One Bug Became Four, and Two Bugs Became One

_Our review loop decides whether a finding is new by its key. In July the key counted one bug four times. We fixed that, and in August it counted two bugs once._

Prompts referenced in [Plutarch TX](https://plutarchtx.substack.com) article **145-one-bug-became-four**.

## How to use

Each `prompt-N.md` file is the prompt itself, with the teaching wrapper
stripped. Open the file, copy the contents, paste into Claude / ChatGPT /
your model of choice. The article (linked above) explains what the prompt
does and what to expect when you run it.
