# The Correction That Would Have Been the Error

_An AI reviewer found a real number, quoted a real line and asked for a fix. Making it would have turned a true line false. A check to run before you change any figure on a reviewer's say-so._

## How to use

Each `prompt-N.md` file is the prompt itself, with the teaching wrapper
stripped. Open the file, copy the contents, paste into Claude / ChatGPT /
your model of choice. The article (linked above) explains what the prompt
does and what to expect when you run it.
