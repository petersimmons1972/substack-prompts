# The Fix Was Merged. The Guard Was Not.

_We fixed a hole in our own safety guard, tested the fix and merged it. Every check passed. For eight days, no copy of the guard we had committed carried the fix._

→ **Read the article:** <https://plutarchtx.substack.com/p/the-fix-was-merged-the-guard-was-not>

## How to use

Each `prompt-N.md` file is the prompt itself, with the teaching wrapper
stripped. Open the file, copy the contents, paste into Claude / ChatGPT /
your model of choice. The article (linked above) explains what the prompt
does and what to expect when you run it.
